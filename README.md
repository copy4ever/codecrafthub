CodeCraftHub Course API
A beginner-friendly Python Flask REST API for managing courses. The API stores course data in a local
courses.json
file and supports creating, viewing, updating, and deleting courses.

Project Overview
CodeCraftHub provides a backend API for course management.

The API runs locally at:

http://127.0.0.1:5001
Port
5000
was occupied by Apple's AirTunes service on macOS, so this project uses port
5001
.

Implemented Features
List all courses
Create a new course
Retrieve one course by ID
Update a course
Delete a course
JSON file storage using
courses.json
Server-generated course IDs
Server-generated creation timestamps
Validation for required fields
Validation for real calendar dates
Validation for allowed course statuses
Partial updates with
PUT
Clear JSON success and error responses
Appropriate HTTP status codes
File-storage error handling
Course Fields
Each course contains the following fields:

Field	Description
id
Server-generated integer
name
Required, non-empty string
description
Required, non-empty string
target_date
Real calendar date in
YYYY-MM-DD
format
status
Not Started
,
In Progress
, or
Completed
created_at
Server-generated timestamp
The server generates
id
and
created_at
. These values are preserved when a course is updated.

Valid status values are:

Not Started
In Progress
Completed
The
target_date
must be a real calendar date. For example,
2026-02-30
is invalid because February does not have 30 days.

Installation on macOS
1. Open Terminal
Open the macOS Terminal application.

2. Navigate to the project folder
cd ~/codecrafthub
3. Create a Python virtual environment
python3 -m venv .venv
The virtual environment keeps this project's Python packages separate from other projects.

4. Activate the virtual environment
source .venv/bin/activate
After activation, the terminal prompt usually shows
(.venv)
.

5. Install the project dependencies
pip install -r requirements.txt
Starting the Server
From the project directory, activate the virtual environment and start Flask:

cd ~/codecrafthub
source .venv/bin/activate
python -m flask --app app run --host=127.0.0.1 --port=5001
The API is then available at:

http://127.0.0.1:5001
Keep this Terminal window open while using the API.

Port
5000
was occupied by Apple's AirTunes service, so the Flask server is configured to use port
5001
.

1. List All Courses
Request
GET /api/courses
curl example
curl -i http://127.0.0.1:5001/api/courses
Successful response
HTTP status:

200 OK
Response format:

{
  "success": true,
  "count": 1,
  "courses": [
    {
      "id": 1,
      "name": "Python Fundamentals",
      "description": "Learn the basics of Python programming.",
      "target_date": "2026-06-30",
      "status": "Not Started",
      "created_at": "2026-01-15T10:30:00"
    }
  ]
}
The
courses
array is empty when no courses have been created:

{
  "success": true,
  "count": 0,
  "courses": []
}
2. Create a Course
Request
POST /api/courses
A course must include:

name
description
target_date
status
curl example
curl -i -X POST http://127.0.0.1:5001/api/courses \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Flask Web Development",
    "description": "Build web APIs using Python and Flask.",
    "target_date": "2026-07-15",
    "status": "Not Started"
  }'
Successful response
HTTP status:

201 Created
Response format:

{
  "success": true,
  "message": "Course created successfully",
  "course": {
    "id": 1,
    "name": "Flask Web Development",
    "description": "Build web APIs using Python and Flask.",
    "target_date": "2026-07-15",
    "status": "Not Started",
    "created_at": "2026-01-15T10:30:00"
  }
}
The actual
id
and
created_at
values are generated by the server.

3. Retrieve One Course
Request
GET /api/courses/<course_id>
Replace
<course_id>
with the numeric ID of a course.

curl example
curl -i http://127.0.0.1:5001/api/courses/1
Successful response
HTTP status:

200 OK
Response format:

{
  "success": true,
  "course": {
    "id": 1,
    "name": "Flask Web Development",
    "description": "Build web APIs using Python and Flask.",
    "target_date": "2026-07-15",
    "status": "Not Started",
    "created_at": "2026-01-15T10:30:00"
  }
}
If the course does not exist, the API returns:

404 Not Found
Example error response:

{
  "success": false,
  "error": "Course not found"
}
4. Update a Course
Request
PUT /api/courses/<course_id>
PUT
allows partial updates. You can provide one field or several fields. Fields that are not included remain unchanged.

curl example: update one field
curl -i -X PUT http://127.0.0.1:5001/api/courses/1 \
  -H "Content-Type: application/json" \
  -d '{
    "status": "In Progress"
  }'
Successful response
HTTP status:

200 OK
Response format:

{
  "success": true,
  "message": "Course updated successfully",
  "course": {
    "id": 1,
    "name": "Flask Web Development",
    "description": "Build web APIs using Python and Flask.",
    "target_date": "2026-07-15",
    "status": "In Progress",
    "created_at": "2026-01-15T10:30:00"
  }
}
The server-generated
id
and
created_at
values are preserved during updates.

curl example: update multiple fields
curl -i -X PUT http://127.0.0.1:5001/api/courses/1 \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Learn Flask REST API development.",
    "target_date": "2026-08-01",
    "status": "Completed"
  }'
5. Delete a Course
Request
DELETE /api/courses/<course_id>
curl example
curl -i -X DELETE http://127.0.0.1:5001/api/courses/1
Successful response
HTTP status:

200 OK
Response format:

{
  "success": true,
  "message": "Course deleted successfully",
  "deleted_course": {

    "name": "Flask Web Development",

Troubleshooting
python3: command not found
Python may not be installed or may not be available in your PATH. Install Python 3, then verify it:

python3 --version
No such file or directory: .venv/bin/activate
Make sure you are in the project directory:

cd ~/codecrafthub
If the virtual environment does not exist, create it:

python3 -m venv .venv
Then activate it:

source .venv/bin/activate
Flask cannot find the application
Confirm that
app.py
exists in the current directory:

cd ~/codecrafthub
ls
Start Flask using:

python -m flask --app app run --host=127.0.0.1 --port=5001
Port 5001 is already in use
Another process may already be using port
5001
. Check which process is using it:

lsof -i :5001
Stop the unnecessary process, then start Flask again.

Connection refused when using curl
Make sure Flask is running in the first Terminal window:

python -m flask --app app run --host=127.0.0.1 --port=5001
Also confirm that the curl commands use port
5001
:

http://127.0.0.1:5001
A request returns
400 Bad Request
Check that:

The request includes the
Content-Type: application/json
header.
The JSON has matching braces and quotation marks.
All required fields are included for
POST
.
status
is one of the three valid values.
target_date
is a real date in
YYYY-MM-DD
format.
String fields are not empty.
A request returns
404 Not Found
Check that:

The URL contains the correct course ID.
The course has not already been deleted.
The course ID is an integer.
Courses are not being saved
The API stores courses in
courses.json
next to
app.py
. Confirm that the application has permission to read and write files in:

~/codecrafthub

500 Internal Server Error
